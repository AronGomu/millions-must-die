Determinism contract

Exact

  • Scenario bytes/hash
  • Obstacle/destination layout
  • Dijkstra integer integration
  • Tie order
  • Agent iteration/recycle order
  • Count + tick number

Tolerant

  • `f32` positions/velocities
  • Normalized vectors
  • Cross-CPU final checksum
  • Quantize before checksum
  • Bound drift in tests

Failure handling

  • Invalid/hash-drifted scene → startup fail.
  • Unreachable spawn → scenario fail.
  • Post-warmup allocation → benchmark fail.
  • Population change → test/runtime invariant fail.
  • Cross-platform checksum outside tolerance → native correctness fail.
