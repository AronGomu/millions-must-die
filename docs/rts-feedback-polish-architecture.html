Architecture · RTS phase 1.1 extension LANDED

Feedback polish without contract drift

The shipped design for control feedback, settings manipulation, procedural world grid, assisted building interaction, positional commands, and order-scoped gather collision. App owns environment/UI. RtsWorld owns deterministic gameplay policy. Horde sim/ remains separate — ADR 009 soft separation, still overlap-capable.

Ownership map

APP / UI

Input + settings transaction

src/rts_run.rs retains pointer owner, text/slider/scroll state. src/rts_ui.rs maps stable controls to changes. src/rts_settings.rs persists schema-1 additive fields.

ENGINE / RENDER

Pure hit + pack projection

rts/hud.rs owns every rect/state, pinned once before any behavior ticket. rts/pack.rs projects grid/ghost/selection/drag box. render/instance.rs adds the texture-free diagonal line sentinel both the grid and the drag box draw with.

RTS WORLD

Deterministic gameplay policy

rts/build.rs ranks placement candidates. rts/world.rs applies gather pair policy. rts/collision.rs stores pair bytes; geometry stays pure.

Input → frame sequence

Stable control model

Identity separate from value

Down/up compare ControlId, never value-bearing hit. Slider x may change while identity remains KeyboardPanSlider. Scrollbar retains ScrollbarThumb. Modal down cannot become world up.

Visual precedence: Disabled → Pressed → Hover → Selected → Idle.

Numeric lifecycle

  • 3-byte ASCII digit buffer; no per-frame heap string.
  • Enter/blur/focus loss → parse, clamp, nearest-step snap, transaction.
  • Empty → restore original, no save.
  • Escape → restore + consume before menu FSM.
  • OS focus order: finalize → stop text → clear pointer/keys → pause reason.

Scrollable settings projection

Pinned geometry

  • Panel [440,100,1040,880], centred on x=960.
  • Viewport [456,160,1008,720]; scrollbar [1432,160,16,720].
  • Content 848px → max scroll exactly 128px at a 72px step.
  • Pan tracks and [1170,288] unchanged; audio block on 96px pitch.
  • GRID_CONTROL_RECT [568,564,784,32] is visible at offset 0.

Wheel is a mapped pointer event

  • viewport.map_pointer first; letterbox bars drop the event.
  • Settings page + point inside the body viewport, or nothing happens.
  • Flipped negates; fractional deltas truncate; zero emits no command.
  • Scripted runs normalise gameplay to defaults, so show_grid in the exit line cannot depend on the machine.

Procedural world grid

O(width + height), not O(cells)

for x in 0..=width:
  line(project(x,0), project(x,height))
for y in 0..=height:
  line(project(0,y), project(width,y))

512×512 max → 1,026 lines. Overlay reserve = max 2,048 selection rings + 1,026 grid lines.

Second procedural sentinel

  • uv_rect.x < -1.5 → diagonal line.
  • -1.5 ≤ x < 0 → ring.
  • x ≥ 0 → atlas sprite.
  • VS rotates skinny quad along segment.
  • FS returns premul tint; no slot-0 sample.
  • Same primitive draws the drag box: Prop::PanelFill's dark 78%-alpha texel makes texel * tint unable to produce a pure green.
  • 48-byte CPU/GPU instance layout unchanged.

Placement + building seams

PLACEMENT

One candidate fn

placement_candidate owns raw min, bounded search, and the tie rule. Distance is measured from the saturated raw min corner — the cell the ghost is drawn at — so the edge of the map ranks the same way the middle does. Ghost + click consume the same result. placement_valid stays sole rule source.

PICK

One geometry derivation

building_quad_px feeds pack + building_screen_rect. Pick = rendered rect ∪ footprint. Owner/depth ties unchanged.

DETAIL

Six total lines

Kind, then READY/build %, supply grant, compact cap-5 W/S queue, head %, rally. Stack buffers + direct glyph pushes keep HUD allocation-free.

Gather collision state machine

and back to HARD
Policy scope: current active pair or exact remembered exit pair ignores mutual dynamic collision. Static world + hard third bodies never ignore. Advance is 255→1, n→n+1; an attempt that reaches contact clears to 0 in the same tick, before normal movement, so a separated pair cannot re-merge on the tick it separated.
Coherence: helper must cover repair, sweep, mover/displaced, displaced/third, displaced/displaced, arrival, policy oracle. Geometry fns stay pure.
No terminal grace: a failed fallback does not park the pair at 12. It returns to 0, is counted by body_overlaps, reports TickError::UnrepairableOverlap, and is retried by generic repair next tick — necessary because RtsWorld::tick returns () and the app never polls last_tick_error.
Provenance survives relocation: a fallback clears only the relocated worker's 1..=12 entries. 255 entries stay — that worker may still be an active gather partner of a third, and every active pair must carry provenance into the hash.
