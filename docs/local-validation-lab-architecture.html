Benchmark verdict

Pass

  • Every host same source/workload
  • All manifests exact
  • Native smoke/golden pass
  • Rust frame alloc = 0
  • 50k absolute + calibrated relative gates pass

Inconclusive/block

  • MAD noise rejection
  • Reset/attestation failure
  • Missing host/report
  • Mixed source hash
  • Baseline needs recalibration

Residual risk

Whole-disk/EACS reset cannot clear every firmware component. Host/source identity can be attested; candidate behavior cannot. Coordinator recomputes policy from raw evidence, yet candidate may forge current-run output or deny service. Policy: manual review, external collection, quarantine drift, reflash/replace. No perfect containment claim.
