Evidence limits

  • SDL3 has no timestamp-query API
  • Fence latency includes queue delay
  • True GPU timing uses external profiler
  • Driver allocs outside Rust allocator

Unsafe seam

render/unsafe_sys.rs exists only after proven high-level wrapper gap. Each use records missing API, ownership/lifetime invariant, upstream issue/version, native tests. No backend-native Vulkan/D3D12/Metal handles for timestamps.

Failure states

  • Wrong backend/software adapter → startup fail.
  • Shader/resource layout mismatch → startup fail.
  • Readback dimension/hash mismatch → native smoke fail.
  • Golden delta above backend tolerance → correctness fail.
  • Rust render-loop allocation after warmup → benchmark fail.
  • 100k perf miss → report only.
