1. What visual contract should every interactive control use?

Current modal rectangles have no hover/pressed state, while HUD menu remains an icon; exact scope controls UI state and render work.

2. Should Close Menu preserve a separate manual pause?

Current pause reasons are independent; “continue game” could mean remove menu pause only or force all pauses off.

3. How should F10 behave from each menu page?

Escape navigates one level; “toggle” needs a distinct rule while Settings is open.

4. How should typed numeric edits validate and commit?

Persisted pan and volume values currently allow fixed steps only; hand input needs deterministic commit and error rules.

5. What should clicking an audio channel label do?

Current volume 0 mutes but loses prior level; separate mute state changes persisted schema and gain calculation.

6. Which settings scrolling controls are required?

Current fixed panel has no wheel event, clipping window, scrollbar, or scroll offset.

7. Where should the world grid appear and what is its default?

No grid render exists; scope decides renderer cost, visual density, and persisted setting default.

8. What exact behavior makes building placement easier?

Exact green candidates already validate and commit; only invalid-near-valid behavior lacks a contract.

9. Which building click shape and stats should ship?

Buildings currently click through ground footprint only and show kind, READY/build %, rally; upper sprite pixels and queue details are gaps.

10. What does “normal command-grid keybinds” mean?

Barracks→Soldier button already exists at slot 0, but key S is semantic, not slot-positional; full 3×3 mapping conflicts with X cancel.

11. How should area-selection border differ from current green border?

Current code already draws four 2px green edges with no fill; visual acceptance needs exact intended delta.

12. Which worker-worker pairs should ignore collision during gathering?

Gather has ToNode, Mining, Returning phases; exact pair rule changes ADR 017’s unconditional no-overlap invariant.
