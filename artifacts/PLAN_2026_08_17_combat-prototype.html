Combat model (settled)

Damage

Instant-hit on cooldown. Per hit = max(1, damage − armor). Flat ints, no types/regen/crits. All placeholder — balance = phase 5.

Stats

Soldier 40 HP · dmg 6 · cd 15 · range 24
Ghoul 30 HP · dmg 5 · cd 30 · range 8 · 18 c/s
Turret 150 HP/1 · dmg 10 · cd 20 · range 36
HQ 400/2 · Depot 150/1 · Barracks 200/1 · Worker 25

Firing rules

Idle + AttackMove auto-acquire, fire in place. Attack closes then fires. Move/Gather/Build never fire. Nearest in range, lowest-slot tie.

Enemy AI

March on objective = approach cell of nearest player building (HQ first). One shared pooled field for hundreds. HQ dead → next building → none → Idle. Ordinary hard pairs — ADR 021 exception not widened.

Death

Units despawn. Buildings destructible incl. HQ: un-stamp → invalidate all fields, queue cancel no refund, supply revoke. Sandbox — no win/lose screen.

Enemies are

RTS entities, OWNER_ENEMY=1, no supply, never produce. Horde sim/ frozen; 400 ≠ phase-3 horde claim.

Gate timeline — the load-bearing decision

Proof forced a deviation: settled "~10 pre-placed" Ghouls would reach the base by ~tick 810 and kill the HQ ~tick 1170 — inside both phase-1 scripts' pinned windows and rts_cli_contract's 3000-frame pins, which cannot be honestly re-baselined. Approved resolution: waves only, first spawn tick 3000.
Consequences, all specced in T7: old scripts' counts provably unchanged → re-baseline = sidecar regen + new zero-token pins only; 8 long-horizon engine tests (rts_economy×4, rts_nav_staleness×4) repoint to byte-identical enemy-free fixture_rts_baseline_v1; RUN_DEADLINE 120→300 s; gate line in docs/05-testing.md + README mirror; exit line printed at its one real site in finish().

Detail-pass amendments (codebase-forced)

  • Armor = kind table, not a column. DamageResult = Damaged | Killed | Indestructible | NoTarget. Building death revokes supply via existing Supply::revoke_cap; HQ death clears start_hq.
  • Combat fixture keeps filename fixture_rts_combat_v1.ron but carries version: "rts_prototype_v1" (validator requires rts: block iff that version); not in ALL_FIXTURES.
  • Enemy objective = approach cell (pooled field cannot target a blocked footprint cell). Counters hashed. Combat→movement halt via combat_hold.
  • T4 needs zero new script tokens: key:a = ExecuteSlot(3) already exists; Attack slot 3, Stop slot 4; attack voices as VoiceCue::Move; 2 new icons via xtask props-sheet regen.
  • Costs live in build.rs; TURRET_BUILD_TICKS = 180 (== Depot). Turret fire silent + unanimated → named gap.
  • Bar/flash assembly in rts/pack.rs; bars never in world hash; offscreen exit lines byte-identical.
  • ADR 022/023 + architecture page ship with this plan — T8 hard-stops if absent (every_doc_link_resolves).
