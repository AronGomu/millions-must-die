Phase 1 — RTS Engine Prototype

Sixteen commit-sized tickets that put camera, selection, workers, economy, building and unit production on top of the phase-0 engine — thin, vertical, and without moving a single phase-0 hash. Index: artifacts/PLAN_2026_08_10_rts-engine-prototype.md.

Goal

Prove the custom engine can run real-time-strategy mechanics, not just a horde walk. All six phase-1 systems present end to end on a new horde-free scene.

Success = cargo run -- rts --frames 1600 --inject-input-file assets/scenarios/rts_acceptance_v1.script exits 0 having panned the camera, box-selected workers, gathered both resources, placed and finished a Depot and a Barracks, and produced a Soldier bounded by supply — every step asserted headlessly and deterministically, with the whole phase-0 merge gate still green and the render golden byte-unchanged.

Assumptions

  • artifacts/ (hyphen) is this repo's artefact directory. Repo convention wins over the skill's spelling.
  • Phase-0 contracts stay frozen: MAX_LIVE_AGENTS = 5_000, SpriteInstance at 48 bytes, atlas_count/direction_count/frame_count = 4/8/4 for every scenario family, testkit gated out of the shipping binary, no GitHub Actions.
  • New ScenarioSpec fields are #[serde(default)], so every tracked .ron keeps its exact bytes and its .sha256 stays valid. No phase-0 asset is regenerated.
  • run and its 24 CLI-contract cases are untouched. RTS ships as a new subcommand with its own parser and stdout contract.
  • InputAction/BoundKey are not extended; RTS input is a separate RtsCommand enum, so input_actions_are_stable cannot be perturbed.
  • The phase-0 golden stays byte-identical: with an empty UI layer the scene pass emits exactly the phase-0 draw order.
  • Determinism is same-host, same-binary. f32 is not claimed bit-identical across builds.
  • Placeholder art is generated from code — no source image, no third-party licence obligation.
  • Every ticket is mutation-verified in both directions, matching the T30–T33 and T0–T10 standard.
  • Zero-allocation is restated, not weakened. One documented exception: a flow-field miss may grow the reused scratch heap once.

Decisions taken before the first line of code

Thin vertical slice

Scope

All six systems present, none deep. Building the control layer now and the economy later would leave the phase's actual question unanswered for another phase.

Horde-free scene

Scenario

rts_prototype_v1 requires hard_agent_count: 0. Combat is phase 2; a zombie that cannot be fought is cost with no payoff.

Two resources + supply

Economy

The 500-population cap is a stated pillar. Supply is what makes it a mechanic rather than a number — and it is reserved at enqueue, or the cap is decoration.

Flow-field pool, not A*

Navigation

8 preallocated fields keyed by destination, LRU. Units sharing a destination share a field — group cohesion for free, one rebuild instead of N.

Texture slots, not more atlases

Render

DrawGroup.atlas_id becomes a slot into a flat 9-texture table. One integer changes meaning; the shader, vertex format and 48-byte instance do not.

Pan, not zoom

Camera

Zoom multiplies through the depth normalisation, the cull and every golden, and non-integer tile scales shimmer on pixel art. Deferred, deliberately.

Generated placeholder art

Assets

No source image, no licence obligation, tracked by sha256 and regenerated by xtask atlases --check. Real art later is a generator swap.

Bitmap-font HUD

UI

A prototype whose resources you cannot read is not demonstrable. Lowercase is a fallback box glyph on purpose, so a missed uppercasing is visible.

What every ticket must satisfy

  • TDD, mandatory. Red first, named tests, behaviour not implementation.
  • Mutation-verified, both directions. Each ticket lists its injections; each must redden a named test and green again on revert.
  • The app compiles and the gate passes after every commit. No ticket leaves a broken path.
  • The horde does not move. run --agents 5000 --frames 300 exit-line hash= is asserted unchanged, ticket by ticket.
  • The golden is compared, never regenerated. git diff --stat HEAD -- lab/goldens/ must be empty.
  • No performance number, anywhere. no_perf_claim_in_docs and gate_list_has_no_perf_thresholds still bind.
