Lock RTS system semantics

Round 1 fixed product direction. These downstream choices resolve hard-collision edge cases, display transforms, HUD limits, map bounds, and audio lifecycle. Then implementation tickets can contain zero design guesses.

1. Should the 3-cell body also stay clear of terrain, buildings, and map edges?

Current nav validates center cells only; full-body clearance can make narrow routes impassable.

2. How should load and production handle occupied spawn space?

Tracked scene starts six workers one cell apart; repeated production can reuse one exact cell.

3. How should group movement finish without merging at one destination?

Current shared 1.5-cell arrival disk cannot hold two radius-3 units.

4. How should fixed 1920×1080 visuals fit other window shapes?

Current renderer stretches; mouse coordinates no longer match visuals outside exact 1920×1080.

5. What sizes should exclusive fullscreen and windowed mode use?

Borderless desktop default is settled; other two mode transitions need deterministic dimensions.

6. What else should happen when game window loses focus?

Pointer release is settled; held pan keys and active drags otherwise remain latched.

7. What defaults and range should camera speed sliders use?

Current shared speed is 24 cells/s; workers become 30 cells/s.

8. How should center selection panel handle single and multi-selection?

Selection can hold 2,048 entities; current HUD only describes lowest-slot primary.

9. What fixed shape should the command grid use?

Worker has 3 build actions; producers have 1 action each; empty slots remain disabled.

10. How should minimap map and viewport be projected?

Playable map is square cell-space; world display is isometric diamond.

11. What engine cap should validate RTS playable-map dimensions?

Current family is locked to 320×320 = 102,400 cells; larger pooled flow fields multiply memory by eight slots.

12. Exactly which unit interactions should emit voice beeps?

Per-unit cap is settled; accepted-vs-attempted events and re-selection still need meaning.

13. What should use the new SFX volume bus in v1?

Unit beeps belong to voice bus; SFX slider needs honest audible content or explicit reservation.

14. What defaults and range should volume controls use?

Master multiplies music, voice, and SFX; safe defaults prevent clipping from eight beeps.

15. When should placeholder music play or pause?

Autoplay, looping, menus, focus, and audio failure affect player experience and test policy.
